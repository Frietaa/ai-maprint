# PHASE-00 / TASK-00.02 — React + Vite + TypeScript Foundation

## Status

NOT_STARTED

## Objective

Initialize the frontend workspace for MABA PRINTING using React, Vite and
TypeScript inside `apps/web`.

This task establishes only the frontend technical foundation.

It does not implement the MABA PRINTING product UI or business features.

---

## Context

TASK-00.01 established the repository foundation and npm workspace.

The approved frontend stack is:

- React
- Vite
- TypeScript
- npm

Tailwind CSS, application routing, business UI, authentication, API
integration and product features are outside this task unless explicitly
required below.

---

## Allowed Scope

This task may:

1. Initialize `apps/web` as an npm workspace package.
2. Configure React + Vite + TypeScript.
3. Create the minimum files required for the Vite React application.
4. Configure package scripts required for the frontend foundation.
5. Install only dependencies directly required by the React + Vite +
   TypeScript foundation.
6. Remove default/demo Vite content that is unnecessary.
7. Replace demo content with a minimal neutral application shell proving
   that React renders successfully.
8. Add or adjust frontend-local configuration required for this foundation.
9. Update Project Memory after successful verification.

---

## Required Package

`apps/web/package.json` must represent the frontend workspace.

Use an appropriate workspace package name consistent with the repository.

The package must remain private.

Expected runtime foundation:

- react
- react-dom

Expected development foundation:

- vite
- typescript
- @vitejs/plugin-react
- React TypeScript type packages

Use versions produced by the current compatible Vite React TypeScript
foundation unless an incompatibility is discovered.

Do not add unrelated dependencies.

---

## Required Foundation

The frontend must provide at minimum:

- `apps/web/package.json`
- `apps/web/index.html`
- `apps/web/src/`
- React entry point
- root application component
- Vite configuration
- TypeScript configuration required by the chosen Vite foundation

Additional files generated by the current official Vite React TypeScript
template are acceptable only when they are genuinely part of the foundation.

Remove unnecessary demo assets/content when safe to do so.

---

- navbar
- footer
- catalog
- order forms
- authentication UI
- admin UI
- animations
- product/service cards
- business data
